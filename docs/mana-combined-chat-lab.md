`make chat-lab` now selects one combined fictional-family profile instead of the
original basic demo. `make chat-lab-workspace` is its explicit alias. The former
basic factory/history remains available as `make chat-lab-basic`; its database
is not migrated into or overwritten by the new lab.

This connects existing compatible workflows for practical joint testing. It
adds no production endpoint, agent, model protocol, migration, permission, source

## Scope

The profile combines Parent-Touch manager/clarifications, Child-Safety native
battery/app/day/location reads and changed-source reviews, shared saved counter
comparisons, reminders, Retention support/expiry and the shared tariff catalogue
with currency questions and original-turn results. Nine existing worker lanes
run under their current durable claims. One parent still has one history and one
shared question slot, with 2000 raw parent tokens/day and 2000 global Safety/day.

All data, permissions and model replies are declared fictional. The profile has
no live Firebase/GA4/Manakids adapters, configured-model factory, push gateway,
tariff grant, payment, checkout executor or scheduled collector. It never loads
the deployment settings. Existing separate paid-model/basic, action-card,
test-trial and fixed collection-window labs keep their original isolated modes.
Referral remains deferred pending the real API; this profile does not simulate
it as completed.

Known paid/current profile facts veto contradictory free conversion events.
The initial fictional tariff lasts 30 days; checking it is not a claim that it
expires soon. Test profile controls are fictional observations, not real changes
to a customer's tariff or proof of a paid conversion. Source counter dates and
coverage remain qualified; a last location point is not a route/current presence.

The historical Retention fixture requires an empty lab history; use it first
when testing that branch. It must not insert a fabricated past into an existing
conversation. Starting another mode, opening a tab or refreshing does not clear
budgets/unknown holds or authorize an automatic provider replay.
