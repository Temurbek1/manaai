## Runtime and unchanged public integration

`MANA_CHILD_SAFETY_SOURCE_TOOLS_ENABLED=false` is the default. Explicit activation
requires the existing source runtime, review-first Parent-Touch and separately
configured Child-Safety limits. Sources still use their own private schema-2 cache,
server-only Google credentials, MANA binding, ownership checks and durable limits.
The new workflow creates no startup read, poller, listener or bulk schedule.

The recommended mobile API remains message admission, message status and single
chat history. The phone neither selects tools nor supplies provider credentials.
For a newly captured parent message, Child-Safety can choose the strict
`read_child_battery` tool with one advertised own-child alias. Parent-Touch alone
publishes the qualified answer in the same chat. No new public source endpoint,
payment, device control, tariff grant or independent specialist chat is added.

The SDK is still OpenAI 2.53.0. Model/profile defaults are unchanged. Native
review uses compact host instructions but retains every admitted parent word,
dated fact and qualification. Ordinary protective analyses and historical jobs
keep their original tool-free methods. A source-assisted parent-intent review
is not a full protective assessment or a fresh measurement of the whole family.

## Private family schema 11

The additive adapter extends the existing commercial schema-10 store without
activating its commercial, account, push or proactive flags. It captures native
eligibility only for new review-first turns, outside legacy JSON. Original model,
reasoning effort, verbosity, wall timeout, output ceiling and complete safety
limits are frozen; changing them before execution refuses the captured job.
Old queued v6–v10 turns do not acquire tools after migration.

The private tables bind the originating turn, immutable prepared provider input,
scope/digest, original native call/argument bytes, exact source receipt and two
individual raw usage receipts. Only opaque encrypted reasoning may accompany
the validated call. Provider prose and forged execution results cannot supply
SQL receipts or become permission. At most two generations and one selected
source read belong to the original job. A second native call is never dispatched.

Before each generation the server counts the exact input and admits its output
under the remaining job/server/parent allowance. Verified terminal raw usage is
atomically saved **before** interpreting the decision or dispatching a source.
The first call's known cost remains charged while the unused original allowance
holds the possible continuation. The second call has the same model, input/call
pairing and original intent, plus a completed exact source receipt. Fresh complete
connected-child membership is checked again; aliases cannot be rebound.

Known invalid decisions release unused allowance, not verified spend. A lost
second model receipt retains the first known cost and remaining unknown hold.
Restart, GET, another nonce and midnight cannot repeat generation or refund it.
Verified late usage may settle cost only; it cannot revive a discarded decision.
Lost SQL acknowledgements stop without source/model redispatch. Source unknown
holds and authorization circuits remain independently enforced by the shared cache.

The global daily safety ceiling stays **2000 raw tokens across all parents**.
Parent-Touch retains its separate **2000 raw tokens per parent/day**. Only new
native jobs may reserve the currently available remainder rather than requiring
a full new job cap; old jobs retain their original admission rule. This does not
increase budgets, unblock unknown holds or guarantee that another task fits.

Source observations reach Parent-Touch as typed exact facts, with observation,
server-write and collection dates kept distinct. Internal child IDs are removed
from its source projection. A source-backed reply must preserve each known UTC
observation date; rejected presentation still retains verified model usage.
Unknown measurement/connection remains unknown. Profile connection is not online.
