## Contract

Only newly admitted manager turns capture protocol2. Its strict nested reply,
handoff and tariff branches prevent mixed handoff text or a null reply body.
Earlier local protocol1 captures retain their original flat wire format, even
when their scope had not yet been read. Both protocols normalize to the same
internal typed decision; neither can read the other wire format. One mandatory native
`choose_parent_touch_response` call selects a reply, one clarification, or an
available Child-Safety/reminder/Upsell owner. It replaces the duplicated initial
reply schema plus three separate routing definitions. It does not remove a
semantic choice, user word, owning policy, model review or output floor.

The exact original request digest, manager binding and frozen scope are paired
with a private publication marker. New v2 admission bindings carry the same
version marker; mismatched proofs stop before generation. An accepted typed invocation is audited in
its owning settlement transaction. Native output is processed before accompanying
prose; prose alone is not a fallback. Specialist receipts remain specialist-owned,
and a model decision is never an execution receipt or permission.

Raw verified terminal usage is accounted before JSON/schema/language checks.
Malformed/deep JSON and invalid UTF-8 cannot turn that known cost into a retry.
Unknown submitted calls retain existing holds. A separate rejection journal keeps
only host-allowlisted reasons/failure codes and independently validated call/kind
identifiers, never rejected body/enquiry prose or reasoning.

Old unmarked requests retain their original schema, model choice and replay.
Enabling the flag cannot upgrade a historical request. The regular mobile
message/status/history API and one-parent/one-chat contract are unchanged.
Parent2000/globalSafety2000 raw ceilings, full objectives, strong models and
owning confirmation requirements are unchanged. No cloud collection, source
schedule, push, grant, payment, permission or production change follows.
