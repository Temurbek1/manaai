# Capability matrix

This matrix covers the capabilities stated in `MANA AI.pdf` and `MANA OPERATION AI (1).pdf`.
For MANA AI, “implemented” means the independent request/response analysis contract, deterministic
guardrails, structured model result, and non-executed action proposals exist. Mobile collection and
action execution remain responsibilities of the separate application.
