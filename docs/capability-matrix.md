# Capability matrix

This matrix covers the capabilities stated in `MANA AI.pdf` and `MANA OPERATION AI (1).pdf`.
For MANA AI, “implemented” means the independent request/response analysis contract, deterministic
guardrails, structured model result, and non-executed action proposals exist. Mobile collection and
action execution remain responsibilities of the separate application.

The operation PDF alternates between “10” and “12” labels, but the platform deliberately exposes
four top-level agents. Admin Analysis, Advertising, SMM, Conversion, Upsell, Referral, Win-back,
review analysis, and incident creation are capabilities within those agents. `Child Analysis` stays
in the separate MANA AI product boundary. See `docs/operation-agent-model.md` for the authoritative
grouping, action lifecycle, current-versus-target distinction, and migration plan.
