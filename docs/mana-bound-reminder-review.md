## One review, one exact host proposal

A newly admitted complete literal request may capture a strong-model semantic
review of its already frozen task/date/timezone. The model sees the full original
parent text, authorized profiles, dated limitations and owning reminder context.
It returns either `prepare` or a refusal/essential clarification. It does not
regenerate task/date arguments. `prepare` requests a preview, not approval,
scheduling, delivery or a provider execution receipt.

The SDK can normalize that choice only to the exact private frozen candidate.
SQL independently revalidates the originating request, direct-route fingerprint,
model/binding and captured clarification bit. The new table is paired with a
versioned marker in the direct route's request digest; either missing proof
stops the turn. No old43/44 request gains a review on rearm or restart.

The existing reminder lifecycle still validates the candidate, atomically saves
its exact localized preview, requires the exact parent's separate confirmation,
and freshly verifies ownership before due delivery. The temporary internal ACK
never appears in committed public history. A question uses the existing atomic
parent clarification lifecycle, not an unmanaged question in prose. The protected
extension leaves noncaptured question admission unchanged.

Unrelated Upsell/Retention authority metadata is removed from this owning model
request; all factual JSON remains. A frozen language reference is retained in
full unless it is exactly equal to the complete last parent message. Only that
host-proven duplicate may refer to the same verbatim input instead. The original
effective reminder-owner minimum64 is obtained from the existing manager prompt;
the intermediate raw template's128 was not the old effective reminder floor.
Final child-guidance publication retains its128 minimum. No output floor, raw
allowance or model is reduced to make a diagnostic pass.

Current flags and owning priority fences apply before new submission and final
publication. Late known usage is charged even when a decision is discarded.
Unknown submitted calls retain their original holds across restart and midnight.
Private accepted/decision labels are review observations, never proof that a
reminder was confirmed or delivered. There is no retry, quota reset, source read,
new collector, push activation, tariff grant, payment or transaction.
